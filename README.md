# Parashu
## Parashu: Adversary Emulation OS

"Parashu" means "axe" in Sanskrit, symbolizing the weapon wielded by the deity Lord Parashurama. Designed specifically for offensive cyber security professionals, Parashu Linux is a distribution tailored to facilitate adversary emulation engagements within enterprise environments.

Researchers often struggle with setting up and managing the extensive suite of tools needed for comprehensive adversary emulation. Parashu Linux addresses this by packaging a curated collection of open-source tools and platforms, all pre-configured for efficient adversary emulation and simulation campaigns.
